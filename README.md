# 🎮 俄罗斯方块 Tetris

一个使用纯 HTML + Canvas + JavaScript 实现的经典俄罗斯方块游戏，无需任何依赖，直接打开即可游玩。

## ✨ 特性

- **7 种经典方块**：I、O、T、S、Z、J、L
- **墙踢旋转**：旋转时自动处理边界碰撞
- **硬降预览**：半透明显示方块落点（Ghost Piece）
- **等级系统**：每消除 10 行升一级，速度随等级加快
- **分数计算**：
  - 软降：+1 分/格
  - 硬降：+2 分/格
  - 单消：100 × 等级
  - 双消：300 × 等级
  - 三消：500 × 等级
  - 四消（Tetris）：800 × 等级
- **暂停/继续**、**游戏结束重玩**

## 🎯 操作

| 按键 | 功能 |
|------|------|
| `←` `→` | 左右移动 |
| `↓` | 加速下落 |
| `↑` / `X` | 旋转 |
| `Space` | 硬降（瞬间到底） |
| `P` | 暂停/继续 |
| `Enter` | 游戏结束后重新开始 |

## 🚀 运行

方式一：直接在浏览器中打开 `tetris.html`

方式二：启动本地服务器

```bash
# Python 3
python3 -m http.server 8000

# 然后浏览器访问
# http://localhost:8000/tetris.html
```
